# 06 — Оппортун: протокол прерывания

**What to build:** Подход к вражескому строю начинает стоить дорого. Отряд, вошедший при
перемещении в чужую Зону провокации, взводит её владельцу право внеочередного удара.
Право срабатывает не сразу: удар наносится после того, как цель объявила следующее
действие, но **до** его исполнения — если Отряд решил развернуться к врагу тылом, он
сначала получает удар во Фронт и только потом разворачивается.

Это самая сложная часть ядра, потому что решение внутри прерывания принадлежит другому
игроку. Поэтому «чьего решения ждут» становится Фазой состояния, а не потоком управления:
объявленное намерение уходит в отложенные, держатели отвечают по очереди, и лишь после
последнего ответа отложенное намерение исполняется. Колбэк дал бы то же поведение, но не
пережил бы сериализацию, а дорога в сетевой PvP должна остаться открытой.

В этом срезе Зона провокации — два Гекса Фронта: Оппортун дальнего боя приезжает
отдельным тикетом, чтобы не отлаживать протокол прерывания и конус одновременно.

**Blocked by:** 03 — Атака ближнего боя и конвейер урона.

**Status:** done

- [x] Вход вражеского Отряда в Зону провокации взводит держателю право удара
- [x] Объявление следующего намерения цели переводит Бой в Фазу Оппортуна
- [x] Держатель выбирает ударить или отказаться, и оба варианта расходуют право
- [x] После ответа последнего держателя исполняется отложенное намерение
- [x] Отложенное намерение не исполняется, если цель уничтожена или обращена в Бегство
- [x] Разворот цели происходит после удара — удар приходит по Фронту, а не по Тылу
- [x] Если объявленное намерение — атака по самому держателю, она исполняется раньше его удара
- [x] Оппортун расходует весь Ход бьющего: после него законен только поворот
      (расходует через `spent.attacked` — тот же гейт, что не даёт ударить дважды)
- [x] Отряд, уже атаковавший в этом Раунде, Оппортун наносить не может
- [x] Отряд, не совершающий больше действий, Оппортуна не провоцирует — право сгорает в конце его Хода
      (арминг завязан только на успешный Шаг; постоять и завершить Ход — не взводит ничего)
- [x] Каждый держатель отвечает не более одного раза за Ход спровоцировавшего Отряда
- [x] Фаза Оппортуна отклоняет любые намерения, кроме ответов держателей
- [x] `legalIntents` в Фазе Оппортуна возвращает только ответы текущего держателя

Решения, не входившие в явный список критериев, но потребовавшиеся по ходу
реализации — см. коммит:

- Удар Оппортуна не провоцирует встречную Контратаку (собственное решение,
  статья не поднимает вопрос: провокатор застигнут посреди намерения, а не
  сам объявляет атаку).
- Валидность намерения проверяется **до** решения об откладывании — иначе
  `legalIntents` считал бы легальным заведомо невозможный шаг только потому,
  что он «откладывается».
- Всплывший попутно баг из тикета 04: Бой обрывался в момент, когда
  последний Отряд стороны ломался Моралью, хотя правило — «не осталось
  Отрядов **на доске**», а бегущий не исчезает мгновенно. Исправлено здесь,
  раз тест на Оппортун впервые дошёл до этого случая.
