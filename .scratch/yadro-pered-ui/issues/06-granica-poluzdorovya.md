# 06 — Граница полуздоровья по букве статьи

**Status:** done

**What to build:** Отряд, потерявший ровно половину Здоровья, обязан наносить половину
Урона. Сейчас на ровно половине он бьёт в полную силу.

Канон: `.scratch/boevaya-sistema/spec.md:86` — «Отряд сохраняет показатели урона, пока не
потеряет половину здоровья; дальше наносит половину урона».

Код: `src/rules/damage.ts:52` — `input.health < input.maxHealth / 2`.

Читать статью так: «пока **не** потеряет половину» — полная сила действует, пока потеря
половины ещё не наступила. На ровно половине она наступила, значит начинается «дальше».
Правильное сравнение — `<=`.

Разница ровно в одной точке шкалы, и именно поэтому её легко не заметить: она видна лишь
у Отрядов с чётным Здоровьем, попавших в неё точным ударом. Тест обязан целиться в саму
границу — здоровье ровно `maxHealth / 2`, — а не рядом с ней.

Правка меняет существующее поведение. Если на ней падают чужие тесты, каждое падение
разбирается по отдельности: это либо тест, закрепивший неверную границу (тогда правится
он), либо задетая механика (тогда правится тикет). Подгонять числа, чтобы позеленело, —
запрещено.

**Checklist:**

- [x] Здоровье ровно `maxHealth / 2`: Отряд наносит половину Урона
- [x] Здоровье на единицу выше половины: Отряд наносит полный Урон
- [x] Здоровье ниже половины: Отряд наносит половину Урона — поведение не меняется
- [x] Граница считается от максимума с учётом Численности, а не от каталожного числа
- [x] Правило действует для всех источников Удара, а не только для обычной Атаки
      (структурно: правило живёт в `resolveDamage`, единственном конвейере, через
      который проходят и `resolveStrike`, и `resolveRangedStrike`, и
      `meleeShotSelfMorale` — обойти его неоткуда)
- [x] Все падения существующих тестов разобраны поимённо и объяснены в заметке

## Что упало

Ровно один тест: **«ровно половина Здоровья ещё не режет Урон»** в
`damage.test.ts`. Он не задевал механику — он прямо утверждал отменяемое
прочтение, строкой `resolveDamage({ ...base, health: 50 })` → полный урон.
Заменён на «на ровно половине Здоровья Урон уже урезан» с тем же входом и
противоположным ожиданием, плюс добавлен парный тест на 51 — чтобы граница
была прижата с обеих сторон, а не только снизу.

Показательно, что **больше не упало ничего** — в том числе контрольный пример
статьи из тикета 10 (`elevation.test.ts`). Значит выдуманная граница нигде не
успела прорасти в другие ожидания, и правка действительно точечная.
