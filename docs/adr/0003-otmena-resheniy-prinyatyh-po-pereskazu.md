# Отмена решений, принятых по пересказу статьи

Первый раунд проектирования вёлся по машинному пересказу статьи «[CF] Боевая система».
После сверки с текстом статьи выяснилось, что пересказ опустил около половины правил и
исказил несколько других. Пять решений первого раунда были приняты на основании неверно
изложенных вариантов и отменены в пользу текста статьи.

| Решение первого раунда | Что говорит статья |
|---|---|
| Инициатива считается по Роду войск, затем по Скорости | Наоборот: сначала по Скорости, Род войск — разрешение ничьи, причём ударная пехота ходит раньше копейщиков |
| Оппортун дают только Отряды ближнего боя | Статья приводит лучников прямо в качестве примера, а лёгкая кавалерия имеет отдельную защиту «не может быть целью оппортуна дальнего боя» — она бессмысленна, если дальний бой Оппортунов не даёт |
| Бежавший Отряд снимается с доски немедленно | Отряд обязан покинуть бой кратчайшим маршрутом, оставаясь на доске |
| Прорыв не срабатывает, если Тыловой Гекс занят | Стоящие позади сдвигаются цепочкой; если Тыл недоступен, цель уходит на Фланг, затем на Фронт |
| Ускорение запрещено, если трата обратит Отряд в Бегство | Такого правила в статье нет: ограничение только одно — не более раза за Ход |

Отменено потому, что каноном объявлена статья (`docs/adr/0002`), а перечисленные
решения принимались в убеждении, что статья на эти вопросы не отвечает. Там, где она
отвечает, собственное решение не нужно.

## Последствие для процесса

Проектные решения по этой системе принимаются только против текста статьи. Машинный
пересказ источника для этого непригоден — он систематически теряет исключения и
частные случаи, а именно в них и живёт баланс.
